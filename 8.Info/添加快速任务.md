# ⚡ 快速添加任务

> 使用 Tasks 插件语法添加任务，支持多种方式：

## 📝 在当前笔记添加任务

直接在笔记中输入任务语法：

```markdown
- [ ] 这是今日任务 #任务/今日
- [ ] 这是一个计划任务 #任务/计划
- [ ] 这是一个日常习惯 #习惯
```

## 🎯 任务标签说明

| 标签 | 用途 | 示例 |
|:---:|:---|:---|
| `#任务/今日` | 今日待办 | `- [ ] 完成学习任务 #任务/今日` |
| `#任务/计划` | 指定日期任务 | `- [ ] 项目任务 #任务/计划` |
| `#习惯` | 习惯养成 | `- [ ] 每日阅读 #习惯` |
| `#项目/项目名` | 项目任务 | `- [ ] 项目开发 #项目/学习前端` |

## ✅ 任务状态

- `[ ]` - 未完成
- `[x]` - 已完成
- `[-]` - 取消/放弃
- `[>]` - 进行中

## 📊 在 Dashboard 查看任务

打开 [[Dashboard]] 查看：
- 今日待办任务
- 进行中项目
- 已完成任务历史

## 🔧 高级用法

### 设置截止日期

```markdown
- [ ] 任务描述 📅 2026-01-30
```

### 设置开始日期

```markdown
- [ ] 任务描述 ➕ 2026-01-25
```

### 设置重复任务

```markdown
- [ ] 每日任务 🔁 every day
- [ ] 每周任务 🔁 every week
```

## 💡 提示

- 使用 Tasks 插件的命令面板快速筛选任务
- 在 [[Dashboard]] 的"今日任务"区域查看所有待办
- 使用 Dataview 查询统计任务完成情况
