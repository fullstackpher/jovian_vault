# [从笔记到系统，手把手教你用Obsidian+Claude Code搭建个人知识管理系统 - 苏米客](https://www.xmsumi.com/detail/2269)

在实践产品经理角色的过程中，我发现**Obsidian与Claude Code的组合**能够突破传统笔记软件的功能边界，从单纯的信息存储工具升级为支撑个人知识体系和目标管理的综合平台。

这篇文章分享我如何通过这套工具链实现从系统搭建、文件结构组织到年度规划拆解的全流程，核心目标是**降低信息输入到内容输出的摩擦**。

## 一、环境配置与插件集成（3步10分钟搞定）

### 1.1 基础工具安装

整个系统的基础由三个部分组成：

-   **Obsidian**：本地知识库管理工具，支持插件扩展（下载地址：https://obsidian.md/）
-   **Claude Code**：提供AI编程和文件生成能力
-   **Skill包**：为Claude定义特定操作技能的配置集

安装前建议参考官方文档完成Claude Code的基础配置。

### 1.2 Claudian插件安装步骤

Claudian是连接Obsidian和Claude Code的桥接插件，实现两个工具的无缝协作。

**安装流程：**

从GitHub Release页面下载最新版本文件：`main.js`、`manifest.json`、`styles.css`  
地址：https://github.com/YishenTu/claudian/releases

在Obsidian vault的插件目录创建文件夹路径：`/path/to/vault/.obsidian/plugins/claudian/`

将下载的三个文件复制到上述目录

![](ReadItLater%20Inbox/assets/从笔记到系统，手把手教你用Obsidian+Claude%20Code搭建个人知识管理系统%20-%20苏米客-nWiyrOwdWk.png)

打开Obsidian设置面板：`Settings → Community plugins → Enable "Claudian"`

![](ReadItLater%20Inbox/assets/从笔记到系统，手把手教你用Obsidian+Claude%20Code搭建个人知识管理系统%20-%20苏米客-P3Tg8LWkl4.png)

启用后，左侧边栏会出现机器人图标按钮，点击可在右侧面板与Claude实时对话

### 1.3 Skills包配置

Skills是为Claude注入特定能力的工具集。推荐安装的开源Skills包包含以下功能：

-   `json-canvas`：创建和编辑Obsidian Canvas可视化文件
-   `obsidian-markdown`：处理Obsidian风格的Markdown格式
-   `obsidian-bases`：处理Obsidian数据库文件

**安装命令：**

```
# 克隆Skills仓库到本地
git clone https://github.com/kepano/obsidian-skills.git ~/.claude/skills/obsidian-skills-main

# 复制到个人Skills目录
cp -r awesome-skill ~/.claude/skills/
```

配置完成后，Claude即可通过API调用这些Skills，为你自动生成Canvas画布、处理Markdown等任务。

## 二、文件结构设计与知识库框架搭建

### 2.1 目录结构设计原则

传统的文件夹结构通常需要手工逐一创建并编写规范文档。

通过Claude Code，整个流程可以一条指令完成。

我采用的目录结构结合了**杜威十进制分类法**和**PARA方法论**（Project、Area、Resource、Archive），根据工作内容定制。

![](ReadItLater%20Inbox/assets/从笔记到系统，手把手教你用Obsidian+Claude%20Code搭建个人知识管理系统%20-%20苏米客-gfLg5ZAx15.png)

**目录结构示例：**

```
vault/
├── 00-收件箱/
├── 01-内容创作/
├── 02-软件开发/
├── 03-产品设计/
├── 04-数据分析/
├── 10-项目进行/
├── 20-持续关注/
├── 30-资源库/
├── 40-归档/
└── aboutme/
```

关键特点：用两位数前缀实现快速定位，避免文件夹嵌套过深影响导航效率。

### 2.2 README规范配置

每个文件夹都应配备README文件，作为**AI的操作指南**。

这一点容易被忽视但至关重要——它让Claude理解该文件夹的用途和命名规则。

**README应包含的核心内容：**

-   **文件夹用途说明**：该目录存储什么类型的内容
-   **命名规范定义**：统一的文件命名标准
-   **AI操作指令**：Claude在此文件夹操作时的约束条件

**命名规范示例（以内容创作文件夹为例）：**

```
MMDD+文件主题.md

示例：0115-如何用AI提升写作效率.md
      0120-产品经理的知识管理系统.md
```

其中MMDD代表月日，便于按时间序列快速查找。

**README末尾的AI指令（关键）：**

```
AI指令: 在此文件夹创建文件前，请先读取本README并严格遵循命名规范。
```

这条指令让Claude养成习惯，每次创建文件时都会自动检查README，无需你每次都重复说明。

### 2.3 一键生成所有文件夹结构

在Claude中执行以下指令：

```
帮我创建以下完整的文件夹结构，每个文件夹下创建README文件说明其用途和命名规范。

文件夹清单：
- 00-收件箱：临时存储，收集灵感和待处理信息
- 01-内容创作：日常创作、文章草稿、发布记录
- 02-软件开发：技术笔记、代码片段、项目文档
- 03-产品设计：产品需求、竞品分析、设计文档
- 04-数据分析：数据报告、复盘总结、趋势观察
- 10-项目进行：正在执行的具体项目
- 20-持续关注：长期追踪的领域、技能提升计划
- 30-资源库：工具教程、参考文献、最佳实践
- 40-归档：已完成或暂停的项目

每个README需要包含该文件夹的定位、存储内容类型和严格的命名规范。
```

执行后，Claude会在你的vault中自动生成完整的目录树和对应的README文件。

### 2.4 About Me文件夹——让AI了解你

这是系统中容易被忽视但最具价值的部分。通过建立About Me文件夹，你可以让Claude建立对你的持久理解，而不是每次从零开始推测。

**文件夹结构：**

```
aboutme/
├── README.md                  ← AI读取指南
├── 我的介绍.md               ← 个人背景、职业经历、核心身份
├── 写作风格.md               ← 语言偏好、格式习惯、表达特点
├── 性格特点.md               ← MBTI性格、沟通风格、工作偏好
├── 内容定位.md               ← 目标受众、内容方向、差异化定位
└── 审稿标准.md               ← 文章质量检查清单、红线标准
```

**各文件应包含的内容样本：**

*我的介绍.md：*

```
- 职位：产品经理，AI产品方向
- 工作经验：5年互联网，2年AI工具领域
- 核心能力：产品策略、用户研究、AI应用设计
- 当前身份：技术博主、独立创作者
```

*写作风格.md：*

```
- 语气：理性、客观，避免夸张修辞
- 结构：问题→分析→实践→总结
- 长度：深度文章1500-3000字，短文300-500字
- 禁用词汇：最强、颠覆、革命性等绝对化表述
```

*审稿标准.md：*

```
检查清单：
- [ ] 核心观点在第一段明确提出
- [ ] 每个建议都有实践案例支撑
- [ ] 避免未经验证的声明
- [ ] 逻辑链条完整，无逻辑跳跃
- [ ] 结尾有具体的行动建议
```

配置About Me后，Claude每次为你创建内容时，都会**自动匹配你的表达风格、理解你的受众定位、遵循你的质量标准**。这相当于给AI装配了一份"个性化操作手册"。

## 三、年度目标拆解与执行系统设计

### 3.1 目标设定的结构化框架

这是系统中最省力且最有价值的部分。关键在于**将模糊的年度目标转化为可执行、可追踪的日周月行动体系**。

向Claude提交目标时，需要包含以下五个维度：

| **维度** | **说明** | **示例** |
| --- | --- | --- |
| 量化目标 | 用数字明确目标终点 | 月访问量从5000做到5万 |
| 当前基线 | 明确起点，便于计算差距 | 目前粉丝2000，差距8000 |
| 变现路径 | 如何将流量转化为收入 | 付费专栏、咨询、赞助 |
| 内容体系 | 围绕什么持续输出 | AI工具、效率提升、独立开发 |
| 执行节奏 | 日周月的具体行动安排 | 日更推文，周出长文，月复盘 |

### 3.2 向Claude提交完整的年度目标

**提交模板（可根据实际修改）：**

```
【2026年度目标设定】

【流量目标】
- 技术博客：月访问量从5000做到5万
- Twitter/X：从2000粉丝做到1万
- 公众号：从3000订阅做到2万

【变现目标】
- 付费专栏：上线¥199专栏，目标500人订阅
- 付费咨询：建立¥500/小时的咨询渠道
- 开源赞助：GitHub Sponsor达到$200/月

【内容体系】
核心方向：AI开发工具、效率提升、独立开发

内容分层：
- 日更：Twitter分享技术心得和工具发现
- 周更：公众号发布深度文章2篇
- 月更：录制技术教程视频2个

【执行节奏】
- 每日：发布1-2条推文，回复社区评论
- 每周：完成2篇长文+1个视频脚本
- 每月：数据复盘+下月规划

【知识库建设方向】
- AI编程工具使用手册
- 独立开发者工作流指南
- 开源项目运营经验总结

请帮我完成：
1. 拆解成12个月的具体里程碑
2. 设计每日执行系统（晨间、工作、晚间各环节）
3. 设计每周行动计划（周一到周日的任务分配）
4. 创建可追踪的周回顾和打卡模板
```

### 3.3 Claude输出的规划成果

Claude会生成一套完整的规划文档，包括：

-   **12个月的里程碑分解**：每个季度的关键目标和预期增长
-   **每日执行系统**：具体到晨间启动、工作时段、复盘总结三个阶段
-   **每周行动规划**：从周一到周日的任务分配逻辑
-   **可复用的模板**：周回顾模板、日打卡模板等

**示例：每日执行系统的三段式设计**

| **时间段** | **关键行动** | **预期产出** |
| --- | --- | --- |
| 晨间（20分钟） | 查看前日数据、制定日目标、浏览行业信息 | 今日优先级清单 |
| 工作时段（6小时） | 内容创作（2h）、社区互动（1.5h）、学习研究（2.5h） | 1-2条高质量推文，文章初稿或代码 |
| 晚间（30分钟） | 数据统计、反思收获、记录问题 | 日记录+明日调整项 |

### 3.4 创建可视化Canvas画布

这是最直观的部分。让Claude用JSON Canvas格式生成两张可视化画布：

**画布1：年度目标全景图**

-   中心节点：年度总目标
-   一级分支：流量、变现、内容三个维度
-   二级分支：每个维度的具体里程碑
-   支撑节点：关键行动和资源

**画布2：周月循环执行图**

-   展示每日三段式的具体任务
-   每周五大工作块的分配
-   月度复盘反馈环

在Obsidian中打开.canvas文件，可自由缩放、拖动、编辑，比文本清单直观程度高数倍，形成了一份可交互的规划指导。

### 3.5 建立追踪模板

Claude帮你生成两类模板：

**周回顾模板（每周日使用）**

```
# W{周数} 周回顾 - {日期}

## 本周目标完成情况
- [ ] 推文发布：__/10条
- [ ] 长文完成：__篇
- [ ] 代码提交：__个

## 数据统计
- 博客访问：+__
- 粉丝增长：+__
- 阅读点赞：__次

## 收获与反思
- 最有效的行动：
- 需要改进的地方：
- 下周重点调整：

## 下周计划
- 优先级任务：
- 内容主题方向：
- 计划学习内容：
```

**日打卡模板（每日使用）**

```
# {日期} 日打卡

## 早晨启动
- 昨日复盘：
- 今日目标（TOP3）：

## 工作记录
创作成果：
社区互动：
学习收获：

## 晚间复盘
- 完成度：__/10
- 瓶颈问题：
- 明日改进：
```

按照命名规范（如`0115日打卡.md`、`W03周回顾-W3.md`），持续填写这些模板，Claude可以根据你的历史记录自动生成数据汇总和趋势分析。

## 四、系统的实际应用效果与迭代空间

### 4.1 系统的当前能力

完整搭建后，这套系统可以支持：

-   **内容共创**：在Obsidian中与Claude实时协作撰写文章，所有版本自动保存
-   **网络内容本地化**：让Claude爬取特定链接内容并转化为你的风格存储
-   **自动化归档**：播客文字稿翻译、推文自动同步下载等
-   **进度可视化追踪**：通过Canvas和模板数据生成月度仪表板
-   **智能建议**：基于你的About Me信息，Claude主动提示内容改进点

### 4.2 持续迭代方向

这套系统目前已运行两周，在实践中呈现出几个值得优化的方向：

-   自动化提取周/月的关键数据，生成更精细的趋势报告
-   将多个文件夹的内容聚合，生成跨领域的主题研究报告
-   建立与外部工具（如Twitter API、Blog Analytics）的数据同步机制
-   优化Claude在读取深层次文件夹结构时的响应速度

## 五、实践建议与总结

### 实践路线

如果你想快速上手这套系统，建议按以下顺序执行：

1.  **第一步（30分钟）**：完成Obsidian + Claudian + Skills的安装配置
2.  **第二步（1小时）**：让Claude生成你的完整文件夹结构和README文件
3.  **第三步（2小时）**：填写About Me文件夹，让Claude了解你的风格和定位
4.  **第四步（2小时）**：提交你的年度目标给Claude，获取完整的规划拆解
5.  **第五步（持续）**：每天使用日打卡模板，每周填写周回顾，让系统自运行

### 核心收获

作为产品经理，我在这个过程中的体会是：**工具的价值不在功能本身，而在于它如何改变你的工作流逻辑**。

Obsidian原本是个本地笔记软件，但通过Claude Code的集成，它从存储工具升级为**思维外化和执行系统**。关键的三个转折点是：

-   从手工建立文件结构 → AI一键生成规范化目录
-   从被动记录笔记 → 主动利用笔记对话优化决策
-   从模糊年度目标 → 结构化的日周月执行体系

这套系统最大的优势是**信息输入到内容输出的全链路摩擦被显著降低**。阅读、学习、笔记、创作、复盘这五个环节不再是割裂的，而是通过Claude的理解能力形成了闭环。
