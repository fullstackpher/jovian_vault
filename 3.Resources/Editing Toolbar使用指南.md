### 插件介绍

Editing Toolbar 是 Obsidian 的可视化编辑工具栏插件，提供类似传统编辑器的按钮功能，降低 Markdown 语法学习门槛。

### 核心功能

| 功能 | 说明 |
|------|------|
| **格式工具栏** | 粗体、斜体、下划线、删除线、高亮等 |
| **标题级别** | H1-H6 标题快速切换 |
| **列表支持** | 有序列表、无序列表、任务列表 |
| **插入元素** | 表格、代码块、引用块、分割线 |
| **Callout 支持** | 多种样式的提示块（info、warning、tip 等） |
| **链接管理** | 快速插入内部链接、外部链接 |
| **编辑辅助** | 查找替换、撤销重做 |

### 使用技巧

1. **悬浮工具栏**：将鼠标选中文本，工具栏会自动出现在光标上方
2. **自定义配置**：可在设置中增删按钮、调整顺序
3. **快捷键组合**：
   - `Ctrl/Cmd + B` → 粗体
   - `Ctrl/Cmd + I` → 斜体
   - `Ctrl/Cmd + K` → 插入链接
4. **表格操作**：选中表格后可调整列宽、插入行列
5. **Callout 快速切换**：输入 `>` 后按空格可快速创建引用块

### 常用快捷键

- 插入 Callout：`shift + alt + c`
- 插入表格：`alt + shift + t`
- 加粗：`Ctrl/Cmd + B`
- 斜体：`Ctrl/Cmd + I`
- 插入链接：`Ctrl/Cmd + K`
- 代码块：`` Ctrl/Cmd + ` ``

### 配置建议

- 推荐启用「悬浮工具栏」模式，减少界面占用
- 可根据个人习惯自定义工具栏按钮
- 配合「模板」插件使用效果更佳
