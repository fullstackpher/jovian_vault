## 核心要点

### 1. 什么是 Claude Code？
- 命令行界面里的 AI 智能体
- 通过自然语言控制电脑
- 可以创建文件、读取文件、执行操作

### 2. 什么是 Obsidian？
- 基于 Markdown 文件的笔记工具
- 可以建立文件之间的双向链接
- 形成"知识图谱"

### 3. 为什么结合使用？
- **解决上下文问题**: 不需要每次都重新解释背景
- **传递项目描述文件**: 把项目需求写成文件直接传给 AI
- **建立思考模式**: AI 可以发现你从未注意到的思维模式

### 4. 实用命令示例
- `Context` - 加载关于你生活/工作/当前状态的完整上下文
- `Daily Brief` - 整合日历、任务、每日笔记
- `Burrow Ghost` - 模仿你的语气回答问题
- `Challenge` - 用 Vault 历史对信念进行压力测试
- `Emerge` - 挖掘 Vault 中隐藏但从未明确表述的想法
- `Trace` - 追踪一个想法随时间的演变

### 5. 核心洞见
- AI 智能体掌握的信息质量决定它能为你做多少事
- 把 AI 当作**思考伙伴**而非只是工具
- Obsidian 是**个人操作系统**的基础
- Markdown 文件是"完美的记忆"
