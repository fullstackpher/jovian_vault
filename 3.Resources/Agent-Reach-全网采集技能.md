# Agent-Reach 全网采集技能

> 给AI装上"全网眼睛"

## 技能简介

Agent-Reach 可以读取 B站、小红书、Twitter 等全平台内容。

## 支持平台

| 平台 | 状态 |
|------|------|
| B站/Bilibili | ✅ |
| 小红书 | ✅ |
| Twitter/X | ✅ |
| YouTube | ✅ |
| 更多平台 | 🔄 |

## 使用场景

- B站视频内容提取
- 小红书笔记采集
- Twitter 帖子分析

## 依赖

- yt-dlp
- feedparser
- curl

## 使用方法

直接说：
- "读取这个B站视频"
- "采集小红书这篇笔记"
- "抓取这个Twitter"

## 配置

可能需要设置代理或 API 密钥
