# Obsidian任务管理教程4：如何安排任务

## 📌 核心要点

### 任务安排的原则
- **聚焦当下**：关注今天和本周可以完成的任务
- **精力匹配**：将高精力任务安排在高精力时段
- **任务切换成本**：尽量减少任务切换，保持专注
- **留有余地**：为突发情况预留缓冲时间

### 四象限法则（艾森豪威尔矩阵）
```
        紧急          不紧急
     ┌──────────┬──────────┐
重要  │  立即做   │  计划做   │
     ├──────────┼──────────┤
不重要│  委托/删除 │  尽量不做  │
     └──────────┴──────────┘
```

### 时间块规划法
- 将一天分为多个时间块
- 每个时间块专注特定类型的任务
- 为重要任务预留充足时间

## 💡 关键技巧

### 1. 优先级排序
- 使用Eisenhower矩阵分类任务
- 考虑任务的影响力和紧迫性
- 定期重新评估优先级

### 2. 日历整合
- 将任务安排到具体日期和时间
- 使用Calendar插件可视化日程
- 设置任务提醒

### 3. 批量处理
- 相似任务集中处理
- 减少任务切换
- 提高效率

### 4. 预留缓冲
- 为意外情况预留时间
- 避免日程过于紧凑
- 保持弹性
