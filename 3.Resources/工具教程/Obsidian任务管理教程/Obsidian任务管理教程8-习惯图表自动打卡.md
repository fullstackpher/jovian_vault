# Obsidian任务管理教程8：习惯图表自动打卡

## 📌 核心要点

### 习惯养成的核心要素
- **触发机制**：建立习惯的触发点
- **最小行动**：设定最小的可执行动作
- **即时反馈**：获得即时的完成反馈
- **持续追踪**：可视化进度和坚持天数

### 习惯追踪的价值
- **可视化进度**：直观看到自己的坚持
- **增强动力**：连续打卡带来成就感
- **发现规律**：了解什么时间、什么情况下容易坚持
- **及时调整**：发现中断时及时调整

### 自动打卡的优势
- **降低记录成本**：自动化减少手动记录
- **减少遗忘**：系统自动记录不遗漏
- **数据准确**：减少人为错误
- **实时统计**：随时查看统计数据

### Dataview习惯统计
```dataview
TABLE
  file.name as 习惯,
  streak("daily", "-00:00") as 连续打卡,
  completions("weekly") as 本周完成
FROM "习惯"
WHERE file.name != "习惯模板"
SORT streak("daily", "-00:00") DESC
```
