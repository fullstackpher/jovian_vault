# Feishu-Bitable 飞书多维表格技能

> 操作飞书 Base 多维表格

## 技能简介

操作飞书多维表格（Bitable/Base）记录。

## 功能

- 列出 Base 内的表格
- 向表中新增记录
- 查询记录
- 更新数据

## 使用场景

- 任务管理
- 数据收集
- 项目跟踪

## 使用方法

直接说：
- "在xxx表新增一条记录"
- "查看xxx表的数据"

## 配置

- FEISHU_APP_ID
- FEISHU_APP_SECRET
