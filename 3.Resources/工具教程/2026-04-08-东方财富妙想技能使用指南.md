# 东方财富妙想技能使用指南

> 整理时间：2026-04-08
> 来源：东方财富妙想Skills官方文档

---

## 📋 技能概览

| 技能名称 | 功能 | 适用场景 |
|---------|------|---------|
| `mx-data` | 金融数据查询 | 查行情、估值、财务指标 |

## 1. mx-data 金融数据

### 功能说明
基于东方财富权威数据库，支持查询股票、基金、指数、债券的实时行情、主力资金流向、估值等数据。

### 支持数据类型
- **行情类**：实时价格、涨跌幅、成交量、主力资金流向
- **财务类**：上市公司基本信息、财务指标、高管信息、股东结构
- **关系类**：股票关联关系、企业经营数据

### 使用示例

#### 查询股票行情
```
"帮我查一下贵州茅台的股价"
"上证指数最新行情"
"创业板指今日涨跌"
```

#### 查询基金数据
```
"帮我查一下易方达蓝筹精选基金的净值"
"几只基金的今日收益对比"
```

#### 查询财务数据
```
"茅台的市盈率"
"平安保险的最近季度营收"
```

#### 查询板块资金流向
```
"今日资金流入最多的板块"
"半导体行业主力资金流向"
```

## 2. mx-search 资讯搜索

### 功能说明
基于金融场景进行信源智能筛选，获取时效性信息、新闻、公告、研报、政策等。

### 支持搜索类型
- 财经新闻
- 上市公司公告
- 券商研报
- 政策解读
- 事件分析

### 使用示例

#### 查询新闻
```
"最近有什么AI科技相关的新闻"
"新能源车最新动态"
```

#### 查询公告
```
"茅台最近有什么公告"
"某上市公司最新公告"
```

#### 查询研报
```
"半导体行业最新研报"
"银行股投资价值分析"
```

#### 事件分析
```
"最近有什么影响市场的重大事件"
"某政策的解读和分析"
```

## 3. mx-xuangu 智能选股

### 功能说明
按财务指标、技术指标、市场数据等条件筛选股票，帮助发现投资机会。

### 常用选股维度
- 估值指标（市盈率、市净率）
- 业绩指标（营收增长、净利润增长）
- 资金流向（主力净流入）
- 技术指标（均线、MACD等）
- 行业板块

### 使用示例

#### 按估值选股
```
"帮我选低估值的银行股"
"市盈率低于行业平均的股票"
```

#### 按业绩选股
```
"哪些股票最近业绩增长超过50%"
"营收连续增长的消费股"
```

#### 按资金选股
```
"主力资金连续净流入的股票"
"今日主力大单买入的科技股"
```

#### 行业筛选
```
"半导体行业低估值的股票"
"医药行业业绩增长快的公司"
```

## 4. mx-zixuan 自选股管理

### 功能说明
管理个人自选股列表，查看自选股实时行情、涨跌统计等。

### 支持功能
- 添加/删除自选股
- 查看自选股实时行情
- 自选股涨跌统计
- 自选股异动提醒

### 使用示例

#### 添加自选股
```
"添加贵州茅台到自选股"
"帮我加入比亚迪到自选"
```

#### 查看自选股
```
"查看我的自选股今日涨跌"
"我的自选股整体表现如何"
```

#### 删除自选股
```
"删除茅台从自选股"
"移除比亚迪"
```

## 5. mx-moni 模拟组合

### 功能说明
创建和管理模拟投资组合，跟踪组合收益率，分析持仓分布。

### 支持功能
- 创建模拟组合
- 买入/卖出模拟交易
- 计算组合收益率
- 持仓分析
- 组合对比基准

### 使用示例

#### 创建组合
```
"创建一个科技股组合"
"新建一个价值投资模拟组合"
```

#### 模拟交易
```
"模拟买入100股茅台"
"卖出我的科技组合里的某股票"
```

#### 查看组合
```
"计算我的组合收益率"
"我的组合持仓分布如何"
```

## ⚠️ 注意事项

1. **数据来源**：所有数据来自东方财富权威数据库
2. **时效性**：行情数据为实时或准实时，财务数据为定期更新
3. **风险提示**：模拟组合仅供学习研究，不构成投资建议
4. **API Key**：需配置 `MX_APIKEY` 环境变量才可使用
