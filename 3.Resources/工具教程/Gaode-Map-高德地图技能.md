# Gaode-Map 高德地图技能

> 位置搜索和路线规划

## 技能简介

与高德地图 API 交互，进行位置搜索和路线规划。

## 功能

- 🔍 地点搜索 (POI)
- 🛣️ 路线规划
- 📍 地理编码
- 🏷️ 关键词搜索

## 使用方法

直接说：
- "搜索附近的餐厅"
- "从A到B怎么走"
- "帮我规划路线"

## 配置

需要环境变量：
- AMAP_API_KEY

## 常用场景

- 查找附近设施
- 出行路线规划
- 地址坐标转换
