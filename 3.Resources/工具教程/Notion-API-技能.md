# Notion API 技能

> 操作 Notion 页面和数据库

## 技能简介

通过 Notion API 创建、读取、更新 Notion 页面和数据库。

## 功能

- 创建页面
- 读取页面
- 更新内容
- 操作数据库

## 配置

1. 创建 Integration：https://www.notion.so/my-integrations
2. 获取 API Key
3. 存储到配置文件

```bash
mkdir -p ~/.config/notion
echo "ntn_your_key" > ~/.config/notion/api_key
```

## 使用场景

- 连接 Notion 知识库
- 双向同步笔记
- 任务管理集成
