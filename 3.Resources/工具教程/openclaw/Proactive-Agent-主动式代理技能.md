# Proactive-Agent 主动式代理技能

> 从任务执行者变为主动伙伴

## 技能简介

让 AI 从被动响应变为主动预测你的需求，并持续改进。

## 核心功能

- 🎯 **主动预测** - 预见需求，主动行动
- 📈 **持续改进** - 从经验中学习
- ⏰ **WAL Protocol** - 工作日志协议
- 🔄 **Working Buffer** - 工作缓冲
- 🤖 **自主定时任务** - 自动执行

## 使用场景

- 需要 AI 主动提醒你
- 需要持续追踪任务
- 需要自动执行重复工作

## 核心概念

### WAL Protocol
Write-Ahead Log，关键细节必须先记录再响应

### Working Buffer
上下文超过60%时启用缓冲模式

### Autonomous Crons
自主定时任务 vs 被动任务
