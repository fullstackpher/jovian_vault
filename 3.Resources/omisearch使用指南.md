# OmniSearch 使用指南

## 简介

OmniSearch 是 Obsidian 的一个强大的搜索插件，提供比 Obsidian 原生搜索更快、更智能的搜索体验。

## 安装

1. 打开 Obsidian 设置 → 社区插件
2. 浏览插件市场，搜索 "OmniSearch"
3. 安装并启用插件

## 核心功能

### 1. 快速启动

- **默认快捷键**: `Ctrl/Cmd + P` （可在设置中自定义）
- 命令面板中搜索 "OmniSearch"

### 2. 搜索语法

#### 基本搜索
```
关键词         # 简单关键词搜索
"精确短语"     # 精确匹配短语
```

#### 布尔运算符
```
关键词1 AND 关键词2    # 同时包含两个关键词
关键词1 OR 关键词2     # 包含任一关键词
关键词1 NOT 关键词2    # 包含关键词1但不包含关键词2
```

#### 高级语法
```
path:笔记夹名          # 在特定文件夹中搜索
tag:#标签名            # 搜索特定标签
file:文件名            # 搜索特定文件
link:[[链接目标]]      # 搜索包含特定链接的笔记
```

### 3. 搜索结果

#### 结果排序
- **相关性排序**: 默认按匹配度排序
- **修改时间排序**: 点击顶部时间标签

#### 结果预览
- 悬停在结果上可预览内容
- 使用 `↑` / `↓` 键在结果间导航
- `Enter` 打开选中的笔记
- `Shift + Enter` 在新标签页打开

### 4. 快捷操作

在搜索结果中：
- `Ctrl/Cmd + Enter` - 创建新笔记
- `Ctrl/Cmd + K` - 将关键词复制到剪贴板
- `Ctrl/Cmd + B` - 在浏览器中搜索
- `Ctrl/Cmd + E` - 在当前笔记中嵌入结果

## 高级设置

### 搜索范围

在插件设置中可以配置：

| 设置项 | 说明 |
|--------|------|
| 最大结果数 | 限制显示的搜索结果数量 |
| 搜索延迟 | 输入后等待多久开始搜索（毫秒） |
| 高亮显示 | 启用/禁用搜索结果高亮 |

### 索引配置

- **自动索引**: 插件自动构建和维护搜索索引
- **索引重建**: 如果遇到搜索问题，可手动重建索引
- **排除文件**: 可配置不参与搜索的文件/文件夹

## 使用技巧

### 1. 快速导航
```
# 快速跳转到最近编辑的笔记
last:3d                # 最近3天编辑的
last:1w                # 最近1周编辑的
```

### 2. 结合标签搜索
```
tag:#工作 AND 项目      # 同时包含#工作标签和"项目"关键词
tag:#读书 NOT fiction   # #读书标签但不包含fiction
```

### 3. 搜索代码块
```
```javascript           # 搜索包含特定语言的代码块
```

### 4. 使用通配符
```
proj*                  # 匹配 project, projects, projecting 等
*ing                   # 匹配以 ing 结尾的词
```

## 实用场景

### 场景 1: 查找相关笔记
输入核心概念后，使用 `Tab` 查看建议，快速找到相关笔记。

### 场景 2: 标签管理
```
tag:#待办              # 查看所有待办事项
tag:#待办 NOT 完成     # 排除已完成的
```

### 场景 3: 内容整理
搜索重复内容或需要整理的笔记：
```
"待整理" OR "TODO"
```

### 场景 4: 项目回顾
```
项目名称 AND last:1m   # 查找最近一个月关于某项目的内容
```

## 常见问题

### Q: 搜索结果不准确？
A: 尝试使用引号进行精确搜索，或使用 AND/NOT 运算符缩小范围。

### Q: 搜索速度慢？
A: 在设置中增加搜索延迟时间，或减少最大结果数。

### Q: 找不到某些笔记？
A: 检查是否在排除文件列表中，或尝试重建索引。

### Q: 快捷键冲突？
A: 在插件设置中自定义快捷键，或在 Obsidian 全局快捷键设置中调整。
