# Self-Improving-Agent 自我改进代理技能

> 持续学习和改进

## 技能简介

记录学习、错误和纠正，持续改进 AI 能力。

## 核心功能

记录以下内容：
- ❌ 命令/操作失败
- ✏️ 用户纠正 ("不是这样的" / "其实是...")
- 🆕 请求不存在的功能
- 🔌 API/外部工具失败
- 📚 过时/错误的知识

## 记录文件

- LEARNINGS.md - 学习记录
- ERRORS.md - 错误记录
- FEATURE_REQUESTS.md - 功能请求

## 触发场景

1. 执行命令失败时
2. 用户给出纠正时
3. 请求不存在的能力时
4. 外部 API 超时/失败时
5. 发现知识过时/错误时

## 使用方法

自动触发，无需手动调用

## 价值

- 避免重复错误
- 积累经验教训
- 持续进化
