# OpenClaw-GitHub-Assistant GitHub助手

> 查询和管理 GitHub 仓库

## 技能简介

直接通过 AI 查询和管理 GitHub 仓库。

## 核心功能

- 列出仓库
- 查看 CI 状态
- 创建 Issue
- 搜索仓库
- 查看最近活动

## 使用方法

直接说：
- "查一下这个仓库"
- "看看 openclaw/openclaw 的 star 数"
- "创建一个 issue"

## 配置

需要环境变量：
- GITHUB_TOKEN
- GITHUB_USERNAME

## 常用操作

| 操作 | 示例 |
|------|------|
| 查仓库 | "show me repo openclaw/openclaw" |
| 看 CI | "check CI status" |
| 创 Issue | "create issue for bug" |
