# Foundry 自我进化技能

> 自我书写的编程子代理

## 技能简介

Foundry 是一个"自我进化"的 AI 编程代理，可以：
- 📚 研究文档
- ✍️ 写新技能
- 🔄 自我改进

## 核心功能

| 工具 | 功能 |
|------|------|
| foundry_research | 搜索最佳实践 |
| foundry_implement | 研究+实现功能 |
| foundry_write_extension | 写 OpenClaw 扩展 |
| foundry_write_skill | 写新技能 |
| foundry_extend_self | 写新工具到 Foundry 本身 |
| foundry_evolve | 分析并进化工具 |
| foundry_crystallize | 固化模式为永久钩子 |

## 学习系统

- 从成功/失败中学习
- 工作流模式识别
- 反馈循环追踪

## 成果

- Written: 0 extensions, 0 skills
- Learnings: 0 patterns
- 每小时自动运行 (Overseer)

## 使用方法

需要新功能时说：
- "帮我研究一下这个API怎么用"
- "实现一个xxx功能"
- "写一个新技能"

## 配置

- dataDir: ~/.openclaw/foundry
- autoLearn: true (自动学习)
- sources: docs, github, arxiv, experience
