# Personal-Assistant 个人助理技能

> 每日简报和生产力助手

## 技能简介

生成个性化的每日简报，包含优先级、习惯追踪、自我反思。

## 功能

- ☀️ **早晨简报** - 今日任务、优先级
- ✅ **习惯追踪** - 每日习惯完成情况
- 🌙 **晚间反思** - 一天总结
- 💪 **自我关怀提醒** - 健康提醒

## 使用方法

直接说：
- "今天的简报"
- "给我一个早晨简报"
- "晚间总结"

## 配置

可能需要：
- 日历集成
- 任务管理集成

## 示例输出

```
☀️ 早晨简报 - 3月3日

今日优先级：
1. [ ] 完成项目A
2. [ ] 会议讨论

习惯追踪：
- [x] 早起
- [x] 运动
- [ ] 读书

保持专注！💪
```
