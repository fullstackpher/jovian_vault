# Ontology 知识图谱技能

> 结构化知识管理

## 技能简介

用类型化的知识图谱来组织和关联信息。

## 核心概念

### 实体 (Entity)
所有内容都是实体，有类型、属性、关系

### 关系 (Relation)
实体之间的关联

### 约束 (Constraint)
类型验证，确保数据一致性

## 使用场景

| 触发词 | 操作 |
|--------|------|
| "记住..." | 创建/更新实体 |
| "关于X我知道什么？" | 查询图谱 |
| "把X和Y关联起来" | 创建关系 |
| "显示项目Z的所有任务" | 图遍历 |

## 数据类型

- Person - 人
- Project - 项目
- Task - 任务
- Event - 事件
- Document - 文档

## 优势

- ✅ 结构化存储
- ✅ 关系可追溯
- ✅ 类型安全
- ✅ 可验证
