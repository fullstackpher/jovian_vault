# mh-Obsidian MantouHub版技能

> MantouHub 版本的 Obsidian 操作

## 技能简介

MantouHub 版本的 Obsidian 操作技能，功能与基础版类似。

## 功能

通过 obsidian-cli 操作仓库：
- 搜索笔记
- 创建笔记
- 移动/重命名
- 删除笔记

## 环境要求

需要安装 obsidian-cli

```bash
brew install yakitrak/yakitrak/obsidian-cli
```

## 使用方法

类似 obsidian-direct，但依赖 CLI

## 与 obsidian-direct 对比

| 特性 | obsidian-direct | mh-obsidian |
|------|-----------------|-------------|
| 依赖 | ripgrep | obsidian-cli |
| 平台 | Windows | macOS/Linux |
| 编码 | 已修复 | 需配置 |
