# Newsletter-Digest 新闻简报技能

>  newsletters 和文章摘要

## 技能简介

处理转发过来的 newsletters 和链接文章，提取关键洞察，创建优先阅读列表。

## 功能

- 📧 处理转发 newsletters
- 📄 文章摘要
- 📋 创建阅读列表
- 🧠 学习兴趣偏好

## 使用场景

- 订阅多个 newsletter
- 需要筛选重要内容
- 建立个人知识库

## 使用方法

直接说：
- "总结这个 newsletter"
- "创建阅读列表"
- "我应该读什么"

## 工作流程

1. 接收转发的 newsletter 或链接
2. AI 提取关键信息
3. 按重要性排序
4. 学习你的兴趣

## 优势

- 节省阅读时间
- 不遗漏重要内容
- 个性化推荐
