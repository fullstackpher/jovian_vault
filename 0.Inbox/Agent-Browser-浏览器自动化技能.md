# Agent-Browser 浏览器自动化技能

> Rust-based 头戴浏览器自动化

## 技能简介

快速的头戴浏览器自动化 CLI，让 AI 能够导航、点击、输入和截图。

## 功能

- 🌐 导航网页
- 👆 点击元素
- ⌨️ 输入文本
- 📸 页面截图
- 📝 表单填写
- 🧪 UI 测试

## 安装

```bash
npm install -g agent-browser
agent-browser install
agent-browser install --with-deps
```

## 使用方法

直接说：
- "打开这个网页"
- "点击登录按钮"
- "填写表单"

## 场景

- 网页数据抓取
- 自动化测试
- 表单自动填写
- 网页交互
