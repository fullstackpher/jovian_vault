# JavaScript Date 对象

## 时间的表示方式

- 不同区域位置使用的时间是不同的
- **GMT**（Greenwich Mean Time）：英国伦敦的皇家格林威治天文台的标准时间（位于本初子午线）
	- 其他时区表示：东部时区（GMT+8），西部时区（GMT-8）
- **UTC**（Coordinated Universal Time）：由于地球公转有误差，GMT 不够精确，因此推出了基于原子钟计算的 UTC 标准时间

> [!info]+ GMT vs UTC
> - GMT 主要表示某个时区中的时间
> - UTC 是国际标准时间，更加精确
> - 目前两者数值几乎相同，UTC 更为通用

## 创建 Date 对象

### 直接创建（当前时间）
```js
let date = new Date()
console.log(date) // 当前本地时间
```

### 使用时间字符串
```js
let date1 = new Date("2026-01-01")
let date2 = new Date("2026-01-01T12:30:00")
let date3 = new Date("January 1, 2026")
```

### 使用数字参数（年、月、日、时、分、秒、毫秒）
> [!warning]+ 注意：月份从 0 开始
> 0 = 一月, 1 = 二月, ..., 11 = 十二月

```js
// 年, 月, 日, 时, 分, 秒, 毫秒
let date = new Date(2026, 0, 1, 9, 0, 8, 333)
console.log(date) // 2026年1月1日 09:00:08.333
```

### 使用时间戳
```js
let timestamp = Date.now()
let date = new Date(timestamp)
```

## 获取时间信息

### 获取年份
```js
let date = new Date()
console.log(date.getFullYear()) // 2026
```

### 获取月份（0-11）
```js
let date = new Date()
console.log(date.getMonth()) // 0-11 (0=一月, 11=十二月)
```

### 获取日期（1-31）
```js
let date = new Date()
console.log(date.getDate()) // 1-31
```

### 获取星期（0-6）
```js
let date = new Date()
console.log(date.getDay()) // 0-6 (0=周日, 1=周一, ..., 6=周六)
```

### 获取小时（0-23）
```js
let date = new Date()
console.log(date.getHours()) // 0-23
```

### 获取分钟（0-59）
```js
let date = new Date()
console.log(date.getMinutes()) // 0-59
```

### 获取秒数（0-59）
```js
let date = new Date()
console.log(date.getSeconds()) // 0-59
```

### 获取毫秒数（0-999）
```js
let date = new Date()
console.log(date.getMilliseconds()) // 0-999
```

### 获取 Unix 时间戳
Unix 时间戳表示自 1970年1月1日 00:00:00 UTC 以来的毫秒数。

```js
let date = new Date()
console.log(date.getTime()) // 毫秒级时间戳
console.log(Date.now())     // 直接获取当前时间戳（推荐）
```

## 设置时间信息

### 设置年份
```js
let date = new Date()
date.setFullYear(2027)
console.log(date.getFullYear()) // 2027
```

### 设置月份（0-11）
```js
let date = new Date()
date.setMonth(5) // 设置为六月
console.log(date.getMonth()) // 5
```

### 设置日期（1-31）
```js
let date = new Date()
date.setDate(15)
console.log(date.getDate()) // 15
```

### 设置小时、分钟、秒、毫秒
```js
let date = new Date()
date.setHours(14, 30, 0, 0) // 时, 分, 秒, 毫秒
console.log(date.getHours()) // 14
console.log(date.getMinutes()) // 30
```

### 使用时间戳设置日期
```js
let date = new Date()
let timestamp = Date.now()
date.setTime(timestamp)
```

## 格式化输出

### toString() - 完整日期时间字符串
```js
let date = new Date()
console.log(date.toString())
// 输出示例: "Fri Feb 06 2026 20:32:00 GMT+0800 (中国标准时间)"
```

### toDateString() - 日期部分
```js
let date = new Date()
console.log(date.toDateString())
// 输出示例: "Fri Feb 06 2026"
```

### toTimeString() - 时间部分
```js
let date = new Date()
console.log(date.toTimeString())
// 输出示例: "20:32:00 GMT+0800 (中国标准时间)"
```

### toISOString() - ISO 8601 格式（UTC）
```js
let date = new Date()
console.log(date.toISOString())
// 输出示例: "2026-02-06T12:32:00.000Z"
```

### toLocaleString() - 本地化格式
```js
let date = new Date()
console.log(date.toLocaleString())
// 输出示例: "2026/2/6 20:32:00"

// 指定格式
console.log(date.toLocaleString('zh-CN', {
  year: 'numeric',
  month: 'long',
  day: 'numeric',
  weekday: 'long',
  hour: '2-digit',
  minute: '2-digit'
}))
// 输出示例: "2026年2月6日星期五 20:32"
```

## UTC 方法（获取/设置 UTC 时间）

### 获取 UTC 时间
```js
let date = new Date()

date.getUTCFullYear()   // UTC 年份
date.getUTCMonth()      // UTC 月份 (0-11)
date.getUTCDate()       // UTC 日期 (1-31)
date.getUTCHours()      // UTC 小时 (0-23)
```

### 设置 UTC 时间
```js
let date = new Date()

date.setUTCFullYear(2027)
date.setUTCMonth(5)
date.setUTCDate(15)
date.setUTCHours(14)
```

## 常用场景示例

### 计算两个日期之间的天数
```js
let date1 = new Date("2026-01-01")
let date2 = new Date("2026-02-06")

let diffTime = Math.abs(date2 - date1) // 毫秒差
let diffDays = Math.ceil(diffTime / (1000 * 60 * 60 * 24))

console.log(diffDays) // 36
```

### 格式化日期为 YYYY-MM-DD
```js
function formatDate(date) {
  const year = date.getFullYear()
  const month = String(date.getMonth() + 1).padStart(2, '0')
  const day = String(date.getDate()).padStart(2, '0')
  return `${year}-${month}-${day}`
}

console.log(formatDate(new Date())) // "2026-02-06"
```

### 获取昨天的日期
```js
let yesterday = new Date()
yesterday.setDate(yesterday.getDate() - 1)
console.log(formatDate(yesterday)) // "2026-02-05"
```

### 判断是否是周末
```js
function isWeekend(date) {
  const day = date.getDay()
  return day === 0 || day === 6
}

console.log(isWeekend(new Date("2026-02-08"))) // true (周六)
```

## 常见陷阱

> [!danger]+ 陷阱 1：月份从 0 开始
> ```js
> let date = new Date(2026, 1, 1) // 这是2月1日，不是1月1日
> ```

> [!danger]+ 陷阱 2：日期超出范围会自动进位
> ```js
> let date = new Date(2026, 0, 32) // 自动变为 2026-02-01
> ```

> [!danger]+ 陷阱 3：字符串解析依赖浏览器实现
> ```js
> // 不推荐，不同浏览器可能返回不同结果
> let date1 = new Date("2026/02/06")
> let date2 = new Date("02-06-2026")
> // 推荐使用 ISO 格式
> let date3 = new Date("2026-02-06")
> ```
