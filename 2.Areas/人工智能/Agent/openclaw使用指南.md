## 1. 搜索功能

OpenClaw 自带的联网能力，主要覆盖的是**搜索与抓取**场景：通过搜索引擎拿链接，再把页面内容读下来。更偏向"读资料"，而不是"操作网页"。

### 工作流程
```
web_search（搜索） → web_fetch（抓取）
找链接              读内容
```

### 搜索引擎配置

| 搜索引擎 | 配置方式 | 免费额度 | 适用场景 |
|---------|---------|---------|---------|
| **Brave** | 淘宝购买API Key（需银行卡绑定） | 每月2000次 | 轻度使用 |
| **Tavily** | 官网配置API Key | 每月1000次 | 深度研究（需关闭VPN） |

## 2. 操作浏览器

OpenClaw 支持两种浏览器操作模式：

### 两种模式
- **内置浏览器实例**：开箱即用
- **外部浏览器**：需配置插件使用

### 支持的操作
- 点击、输入、滚动、截图
- 自动填表、网页数据抓取、批量操作

### 环境配置
| 配置项 | 说明 |
|-------|------|
| 浏览器路径 | 指定浏览器可执行文件位置 |
| 显示/无头模式 | 有头（可视化）/无头（后台运行） |
| 页面加载超时 | 防止页面加载卡死 |

> 需要配置 Playwright 或 Puppeteer 环境

## 4. 技能市场

### find-skills（查找技能）

帮你搜索和安装来自 [skills.sh](https://skills.sh) 市场的技能。

#### 适用场景
- 你问"怎么做XXX"时
- 你想"找个做XXX的技能"
- 你问"你能做XXX吗"

#### 使用方法
```shell
npx skills find [关键词]
```

#### 示例
```shell
npx skills find react testing
npx skills find deploy docker
```

#### 功能
- 搜索已有技能
- 展示找到的技能和安装命令
- 直接帮你安装

## 5. 推荐技能

### proactive-agent（必装）

让你的 AI 助手从"等指令"变成"主动出击"。

#### 1️⃣ 主动预判
- 不等你开口就问"需要什么"
- 记住你的偏好，主动应用
- 定期检查重要事项并主动提醒

#### 2️⃣ 记忆持久化
| 机制 | 说明 |
|-----|------|
| WAL Protocol | 关键细节（名字、偏好、修改）立即写盘 |
| Working Buffer | 上下文快满时（60%），自动记录每个交换 |
| Compaction Recovery | 上下文压缩后能恢复状态 |

#### 3️⃣ 自我进化
- 尝试 10 种方法再放弃
- 从错误中学习并改进
- 安全升级（有 ADL/VFM 护栏）

## 6. MCP 服务

MCP（Model Context Protocol）支持多模型接入。

### 支持的模型

- GPT 系列
- Gemini 系列

### 配置方式

- 配置文件设置

## 7. 本地与云端协作

| 模式 | 适用场景 |
|-----|---------|
| 本地部署 | 隐私要求高、需要本地资源控制 |
| 云端协作 | 需要强大算力、多人协同 |
| 混合模式 | 敏感数据本地处理，一般任务云端处理 |

- 数据同步：通过 API 或 WebSocket 保持状态一致
