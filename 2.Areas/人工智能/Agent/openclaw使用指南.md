## 1. 搜索功能

OpenClaw 自带的联网能力，主要覆盖的是**搜索与抓取**场景：通过搜索引擎拿链接，再把页面内容读下来。更偏向"读资料"，而不是"操作网页"。

### 工作流程
```
web_search（搜索） → web_fetch（抓取）
找链接              读内容
```

### 搜索引擎配置

| 搜索引擎 | 配置方式 | 免费额度 | 适用场景 |
|---------|---------|---------|---------|
| **Brave** | 淘宝购买API Key（需银行卡绑定） | 每月2000次 | 轻度使用 |
| **Tavily** | 官网配置API Key | 每月1000次 | 深度研究（需关闭VPN） |

## 2. 操作浏览器

OpenClaw 支持两种浏览器操作模式：

### 两种模式
- **内置浏览器实例**：开箱即用
- **外部浏览器**：需配置插件使用

### 支持的操作
- 点击、输入、滚动、截图
- 自动填表、网页数据抓取、批量操作

### 环境配置
| 配置项 | 说明 |
|-------|------|
| 浏览器路径 | 指定浏览器可执行文件位置 |
| 显示/无头模式 | 有头（可视化）/无头（后台运行） |
| 页面加载超时 | 防止页面加载卡死 |

> 需要配置 Playwright 或 Puppeteer 环境

## 3. 记忆机制

| 类型 | 说明 |
|-----|------|
| 短期记忆 | 当前会话内的上下文保持 |
| 长期记忆 | 可配置向量数据库存储历史交互 |
| 记忆检索 | 基于语义相似度召回相关上下文 |

- 可对接外部知识库（如 RAG 系统）

## 4. MCP 服务

MCP（Model Context Protocol）支持多模型接入。

### 支持的模型
- Claude 系列
- GPT 系列
- Gemini 系列

### 配置方式
- 环境变量配置
- 配置文件设置
- 支持自定义参数：temperature、max_tokens 等

## 5. 本地与云端协作

| 模式 | 适用场景 |
|-----|---------|
| 本地部署 | 隐私要求高、需要本地资源控制 |
| 云端协作 | 需要强大算力、多人协同 |
| 混合模式 | 敏感数据本地处理，一般任务云端处理 |

- 数据同步：通过 API 或 WebSocket 保持状态一致
