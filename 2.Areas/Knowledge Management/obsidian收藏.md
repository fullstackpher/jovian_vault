# Obsidian 收藏功能最佳实践

> 收藏是构建个人知识库的重要入口，通过合理的收藏策略可以快速访问最重要的笔记。

---

## 一、收藏的核心价值

- **快速访问**：将高频使用的笔记、模板、索引页面放入收藏
- **工作流入口**：将项目入口、待办清单、日常笔记快捷方式收藏
- **专注当前**：在处理特定项目时，收藏相关笔记形成"工作集"

---

## 二、收藏方式对比

| 方式 | 快捷键 | 适用场景 | 特点 |
|------|--------|----------|------|
| **星标 (Star)** | `Ctrl/Cmd + D` | 长期高频访问 | 固定位置，适合常用笔记 |
| **书签 (Bookmark)** | `Ctrl/Cmd + Shift + B` | 需要注释和分层 | 可添加描述，支持标签和嵌套 |
| **快速切换器** | `Ctrl/Cmd + O` | 临时快速打开 | 搜索型，不是持久收藏 |

### 推荐策略
- **长期固定内容** → 星标（Star）
- **需要组织结构** → 书签（Bookmark），建立文件夹式收藏
- **临时查阅** → 快速切换器

## 三、星标最佳实践

### 3.1 建议的星标结构

```
★ 星标
  ├── 📁 模板库
  │     ├── Daily Note 模板
  │     ├── 项目笔记模板
  │     └── 会议记录模板
  ├── 📁 项目入口
  │     ├── 当前项目 A
  │     └── 当前项目 B
  ├── 📁 索引导航
  │     ├── 领域地图
  │     └── 技能清单
  └── 📒 常用参考
        ├── 缩写表
        └── 术语表
```

### 3.2 星标管理原则

- **数量控制**：星标不超过 15-20 个，过多会降低效率
- **定期清理**：每月检查星标内容，移除不再需要的项
- **命名规范**：使用 emoji 前缀区分类型，保持一致性
- **建立入口**：收藏索引页面而非散落的子笔记

## 四、书签最佳实践

### 4.1 书签的高级功能

```
书签可以做到：
├── 添加描述（备注）
├── 分配标签
├── 嵌套文件夹结构
├── 标记为重要/紧急
└── 快速复制链接
```

### 4.2 建议的书签结构

```
📌 书签
  ├── 🎯 重要笔记
  │     ├── 核心人生原则.md [重要]
  │     └── 年度目标.md [重要]
  ├── 📚 学习资源
  │     ├── 技术文档收藏
  │     └── 课程笔记索引
  ├── 🛠️ 工作工具
  │     ├── 命令速查表
  │     └── 常用网站集合
  └── 📅 周期性内容
        ├── 周回顾模板
        └── 月度复盘模板
```

### 4.3 书签命名规范

| 前缀 | 含义 | 示例 |
|------|------|------|
| `[重要]` | 高优先级 | `[重要] 年度OKR.md` |
| `[待读]` | 待处理内容 | `[待读] 感兴趣的文章.md` |
| `[参考]` | 外部参考资源 | `[参考] 官方文档.md` |

## 五、收藏策略建议

### 5.1 新笔记处理流程

```
新笔记创建
    │
    ├─► 是否需要长期保存？
    │     ├─ NO → 删除或归档
    │     └─ YES ↓
    │
    ├─► 是否高频访问？
    │     ├─ YES → 加入星标
    │     └─ NO ↓
    │
    └─► 是否需要分类查找？
          ├─ YES → 加入书签（添加描述和标签）
          └─ NO → 仅归档
```

### 5.2 收藏检查清单

在收藏前问自己：

- [ ] 我会在**一周内**再次打开这个笔记吗？
- [ ] 这个笔记是**多个项目的入口**吗？
- [ ] 这个笔记是**模板或工具性**内容吗？
- [ ] 移除它会让我**难以找到**吗？

### 5.3 清理周期

| 周期 | 操作 |
|------|------|
| **每周** | 检查 `[待读]` 书签，处理或移除 |
| **每月** | 审视星标内容，移除不常用的项 |
| **每季度** | 重新评估书签结构，优化组织方式 |

## 六、高级技巧

### 6.1 使用命令面板

- `快速添加书签` - 快速收藏当前笔记
- `在星标中添加` - 将当前笔记加入星标
- `管理星标` - 编辑星标内容

### 6.2 配合 Dataview 使用

```dataview
TABLE file.name, file.tags, file.cday
FROM "Obsidian"
WHERE file.starred = true
SORT file.cday DESC
```

### 6.3 建立"收藏索引"页面

创建一个专门的笔记 `🗂️ 收藏索引.md`，记录收藏逻辑和快速导航：

```markdown
# 我的 Obsidian 收藏体系

## 快速导航
- [[★ 模板库]] → 打开常用模板
- [[📁 项目入口]] → 进入当前项目
- [[📚 学习索引]] → 学习资源总览

## 使用说明
- **星标**：长期固定的入口页面
- **书签**：需要注释的参考资源
```

## 七、常见误区

| 误区 | 正确做法 |
|------|----------|
| 收藏所有笔记 | 只收藏真正高频使用的 |
| 收藏从不清理 | 建立定期清理机制 |
| 结构过于复杂 | 保持扁平、简洁的层级 |
| 忘记使用描述 | 书签一定要加备注说明 |
| 星标和书签混用 | 明确区分使用场景 |

```yaml
# 推荐的收藏结构（可直接复制到 Obsidian）

星标:
  - 📁 模板库/
  - 📁 项目入口/
  - 📁 索引导航/
  - 📓 常用参考/

书签:
  - 🎯 [重要] 核心原则.md
  - 📚 [待读] 阅读清单.md
  - 🛠️ 命令速查.md
  - 📅 周复盘模板.md
```

---

> **核心原则**：收藏是为了**更快地找到**和**专注于重要内容**，而不是为了**收藏本身**。Less is more.
