## 什么是标签

标签（Tag）是 Obsidian 中用于分类和标记笔记的元数据，以 `#标签名` 的形式出现，便于快速检索和筛选。

## 基本语法

| 语法 | 说明 |
|------|------|
| `#标签名` | 单个单词标签 |
| `#标签/子标签` | 嵌套标签（层级分类） |
| `#标签名_描述` | 带下划线的复合标签 |

## 使用技巧

### 1. 标签位置
- 可以出现在笔记的任意位置
- 通常放在开头或结尾便于识别
- 也可以放在正文段落中

### 2. 嵌套标签

```
#领域/知识管理
#类型/教程
#状态/进行中
#项目/产品A/设计稿
```
层级结构有助于组织分类。

### 3. 搜索标签
- 在搜索框输入 `tag:#标签名` 快速筛选
- 或直接点击笔记中的标签进入筛选视图
- 支持通配符搜索，如 `tag:#工作/*` 匹配所有工作子标签

### 💡 标签命名规范建议

| 规范          | ✅ 正确示例                            | ❌ 错误示例          |
| ----------- | --------------------------------- | --------------- |
| 使用 `/` 分隔层级 | `#学习/编程`                          | `#学习_编程`        |
| 统一大小写       | `#Project/Work` 或 `#project/work` | `#Project/work` |
| 避免空格        | `#工作_项目A`                         | `#工作 项目A`       |
| 数字合理使用      | `#2026/年计划`                       | `#26/年计划`       |
| Emoji 可选    | `#⭐重要/工作`                         | -               |

## 常用标签组合模板

以下是一篇标准笔记的标签组合示例：

```
#项目/博客/草稿
#状态/进行中
#类型/文章
#写作/技术
#日期/2026-02
```

对应搜索：
- `tag:#项目/博客` → 所有博客项目笔记
- `tag:#状态/*` → 所有状态标签笔记
- `tag:#写作/技术 AND tag:#状态/进行中` → 写作中且状态进行中的技术文章

## 最佳实践

1. **命名规范**：使用统一的命名风格（如下划线连接或驼峰命名）
2. **避免过多**：每个笔记 2-5 个标签为宜
3. **层级清晰**：使用嵌套标签组织大类
4. **统一归类**：与文件夹结构配合使用
