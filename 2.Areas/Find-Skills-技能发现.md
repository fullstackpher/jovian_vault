# Find-Skills 技能发现

> 发现和安装新技能

## 技能简介

帮助你发现和安装 OpenClaw 技能生态系统中的新技能。

## 使用场景

当你说这些时触发：
- "如何做 X" - 某个常见任务
- "找一下做 X 的技能" - 特定功能
- "有做 X 的技能吗" - 确认是否存在
- "你能做 X 吗" - 扩展能力
- "我想学 X" - 特定领域

## 功能

- 搜索技能
- 安装技能
- 查看技能详情

## 使用方法

直接说：
- "有什么技能可以视频下载？"
- "找一个做知识库的技能"
- "AI 写作有什么技能？"
